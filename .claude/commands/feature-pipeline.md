以下の要件を、3つのサブエージェントに分離して実装する。あなた（メイン）は各エージェントを
順番に呼び出し、ファイル経由で受け渡す「オーケストレーター」に徹する。自分では実装・評価をしない。

要件: $ARGUMENTS

## 手順

1. **Planner** を呼ぶ。
   - 上記要件を渡し、計画ファイル（`.claude/plans/*.md`）を作らせる。
   - 計画をユーザーに提示し、**承認を得る**。修正指示があれば Planner に戻す。

2. **Generator** を呼ぶ。
   - 承認された計画ファイルのパスを渡し、ストーリー単位で実装＋commit させる。

3. **code-evaluator** を呼ぶ。
   - 直近の変更（`git diff`）をレビューさせ、PASS / FAIL を受け取る。
   - **FAIL の場合**: 指摘を Generator に渡して修正させ、再度 Evaluator に回す。
   - **最大3イテレーション**まで。3回で PASS しなければ、計画段階からやり直すことを提案する。

4. PASS したら、最終差分と、各エージェントの判定サマリをユーザーに報告する。

## 原則

- 各エージェントには **ファイルパス・型・ライブラリを具体的に**渡す（曖昧な指示は事故る）。
- エージェント間の受け渡しは**計画ファイル・git diff 経由**にして、コンテキストを汚さない。
- Evaluator の判定は尊重する。メインが勝手に「まあ大丈夫」と上書きしない。
